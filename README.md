# Sunshine Mobile

Turn an Android phone or tablet into a Moonlight host. No PC and no root needed.

> **Early release.** Expect bugs. Not all features are finished.

## What works
- Shows up in Moonlight automatically (no "Add manually" needed)
- Pairing and connecting
- Screen capture and video streaming (H.264)
- Touch and mouse input (basic, still buggy)
- Basic keyboard typing and scrolling
- Settings screen (pointer speed, bitrate, frame rate)

## Not supported yet
- Audio
- Gamepads / controllers
- Error correction, so use fast 5 GHz Wi-Fi

## Setup
1. Download the latest APK from **Releases** and install it.
2. Open the app and tap **Enable remote input (Accessibility)**, then turn on **Sunshine Mobile input**.
   On Android 13+ you may first need to allow restricted settings (App info, ⋮ menu).
3. Tap **Start host** and accept the screen-capture prompt.
4. In Moonlight, pick the device and pair it.
5. In Moonlight, turn off "touchscreen as trackpad" so taps land where you touch.

## Requirements
Android 10 (API 29) or newer, and a Moonlight client on the same network.

## Reporting bugs
Open an issue and include the log from the app's **Copy log** button.
